# Story 1.6: Dynamic browser tab branding

Status: dropped (reversed)

## Story

As a Vantage user,
I wanted the browser tab to show the name and icon of the application I was working on,
so that I could tell applications apart across browser tabs.

## What it does today

This idea was built briefly and then reversed. The browser tab always shows the fixed title **"Vantage"** and the Vantage icon, on every screen, signed in or not. It never changes per page or per application. The open application's name is shown inside the page instead, in the sidebar and breadcrumb.

## Acceptance criteria

1. Given any screen, when it is shown, then the browser tab title is "Vantage" and the tab icon is the Vantage icon.
